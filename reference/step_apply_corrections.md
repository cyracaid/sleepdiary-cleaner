# Step 6 – apply manual corrections

Step 6 – apply manual corrections

## Usage

``` r
step_apply_corrections(x, corrections_df, manual_unusual_df)
```

## Arguments

- x:

  A `sleep_diary` object.

- corrections_df:

  Data frame of manual error corrections.

- manual_unusual_df:

  Data frame of manual unusual-pattern decisions.

## Value

A `sleep_diary` object.
