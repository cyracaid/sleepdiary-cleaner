# Plot a Bland-Altman result

Plot a Bland-Altman result

## Usage

``` r
# S3 method for class 'bland_altman'
plot(x, ...)
```

## Arguments

- x:

  A list returned by
  [`bland_altman()`](https://cyracaid.github.io/sleepdiary-cleaner/reference/bland_altman.md).

- ...:

  Passed to `print.ggplot`.

## Value

The ggplot object, invisibly.
