## 一、Pipeline 逻辑改动 (May 7 Session)

### 1.1 `checkforerrors_processing.R` — 排除 Exercise/Nap 格式检查

**问题**: 运动类型 (`exercisetoday*`) 和午睡时长 (`duration_totalmin_napstoday_PM`) 格式检查产生 ~81% 的 UNUSUAL_VALUE 噪音 (~4,691 条)。这些变量不影响核心睡眠指标 (SOL, TST, SE, WASO)。

**改动**:
- Part A (标记收集): 排除匹配 `exercisetoday|duration_totalmin_napstoday_PM` 的列
- Part 3 (严重度分类): 相同排除逻辑

**结果**:

| 指标 | 之前 | 之后 |
|------|------|------|
| UNUSUAL_VALUE | 2,628 | 8 |
| 总计非 CLEAN | 3,399 | 759 |
| checkforerrors_df 行数 | 4,069 | 1,449 |

### 1.2 `normalize_sleep_time_sequence.R` — 标准化后清除时间戳 checkforerrors

**问题**: `process_timestamp()` 在 `*_checkforerrors` 列写入解析阶段警告（如 "both time and am/pm missing"）。标准化自动修正后这些警告已过时但从未被清除。

**改动**: 在 Section 10 新增清除逻辑 — 如果 `*_corrected` 非 NA，则清除对应的 `*_checkforerrors`：
- `time_bed_am_checkforerrors` → `time_bed_corrected` 有效时清除
- `time_sleep_am_checkforerrors` → `time_sleep_corrected` 有效时清除
- `time_awake_am_checkforerrors` → `time_awake_corrected` 有效时清除
- `time_getup_am_checkforerrors` → `time_getup_corrected` 有效时清除

关键设计: 用 `!is.na(time_*_corrected)` 而非 `corrected == TRUE`，因为很多记录有有效 corrected 值但 `corrected == FALSE`（原始时间序列本身有效，仅输入格式杂乱）。

**结果**:

| 指标 | 之前 | 之后 |
|------|------|------|
| SERIOUS_RED_LINE | 751 | **0** |
| 总计非 CLEAN | 759 | 61 |
| 时间戳 checkforerrors 非 NA | ~771 | **0** |

### 1.3 `checkforerrors_processing.R` — 智能 RED/YELLOW/BEHAVIORAL 三级分类

**改动**:
- **Round 1**: 从 Part A 和 Part 3 排除物质使用时间戳格式列 (`caffeinetoday_PM_checkforerrors`, `alcoholtoday_PM_checkforerrors`, `nicotine_amount_pm_checkforerrors`, `cannabis_amount_pm_checkforerrors`)
- **Round 2**: 重新设计严重度映射为三级体系：
  - **RED**: 数据完整性错误（时间戳格式、SOL 格式）
  - **YELLOW**: 轻度质量问题（WASO 格式）
  - **BEHAVIORAL** (新增): 生活方式/物质使用标记（caffeine >4, alcohol >3）

**结果**:

| 类别 | 之前 | 之后 |
|------|------|------|
| SERIOUS_RED_LINE | 0 | **0** |
| UNUSUAL_VALUE | 8 | **0** |
| BEHAVIORAL (新) | — | **8** |
| CLEAN | 13,929 | **13,929** |
| CLEAN (Manually Fixed) | 53 | **53** |

### 1.4 物质使用阈值调整

| 物质 | 旧阈值 | 新阈值 | 理由 |
|------|--------|--------|------|
| Caffeine | 10 cups/day | **4 cups/day** | >400mg 与睡眠障碍相关 |
| Alcohol | 12 drinks/day | **3 drinks/day** | 大量饮酒影响睡眠结构 |
| Nicotine | 40 doses/day | **1 dose/day** | 任何使用都可能影响睡眠 |
| Cannabis | 10 doses/day | **1 dose/day** | 每日使用与睡眠问题相关 |

## 五、关键设计决策

| 决策 | 理由 |
|------|------|
| 双排除 (Part A + Part 3) 而非删除列 | 保留审计追踪 — 标记存在于原始数据但不触发审查 |
| 基于 `!is.na(*_corrected)` 而非 `corrected == TRUE` 清除 checkforerrors | `corrected == TRUE` 仅表示主动调整(±12h/swap)；很多记录有有效 corrected 值但非主动修正 |
| 物质使用标记 → BEHAVIORAL 而非完全排除 | 分类输出中仍可见供研究者参考，但不触发审查 |
| 物质使用时间戳列从整个 pipeline 排除 | 上下文变量（咖啡时间等），不影响 SOL/TST/SE/WASO |
| 保留 4 个时间戳列为 RED 安全网 | 目前为 0（因 normalize 清除），但如果 normalize 逻辑未来变化，RED 提供回退 |
| SOL → RED, WASO → YELLOW | SOL 是核心指标；WASO 重要但严重度次之 |
| 基于睡眠研究文献的阈值 | 循证阈值而非任意值 |
