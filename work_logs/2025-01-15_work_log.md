## 🔄 0.* **Fix Logic Overview**

1️⃣ **Sleep Date Alignment**:

```
IF sleep_time < bed_time AND (bed_time - sleep_time) > 1 day → sleep_time = bed_time's date
```

If `sleep_time` is earlier than `bed_time` by more than a day (likely a date entry error), adjust `sleep_time` to match `bed_time`’s date.
 **Purpose:** Ensures sleep doesn’t occur before bed, preventing downstream awake/getup errors.

2️⃣ **AM/PM & Midnight Correction**:

```
IF getup_time < sleep_time AND sleep_time >= 18:00 AND getup_time < 12:00 → getup_time += 1 day
```

If `getup_time` is earlier than `sleep_time` and `sleep_time` is ≥18:00 while `getup_time` <12:00, add 1 day to `getup_time` (handles post-midnight cases).
 **Purpose:** Corrects times like “00:15 AM” to the proper next-day time, maintaining logical order.

3️⃣ **Cross-Day Getup Handling**:

```
IF getup_time < sleep_time:
    IF sleep_time >= 18:00 AND getup_time < 12:00 → getup_time += 1 day
    ELSE IF sleep_time < 06:00 AND getup_time >= 12:00 → keep same day
    ELSE → flag but do not swap
```

When `getup_time < sleep_time`:

- Late sleep (`sleep ≥18:00` & `getup <12:00`) → add 1 day
- Early sleep (`sleep <06:00` & `getup ≥12:00`) → keep same day
- Other cases → flag but don’t adjust
   **Purpose:** Handles cross-day getup times, avoids illogical awake/getup swaps.

4️⃣ **Swap Logic Refinement**:

```
awake_time > getup_time → swap only after all date/AMPM corrections, else flag
```

Previously, `awake_time > getup_time` always triggered a swap; now it swaps only after all date/AMPM corrections, otherwise it’s flagged.
 **Purpose:** Prevents unreasonable swaps in extreme cases (e.g., very early awake vs late getup).

5️⃣ **Error Definition Update**:

```
track bed>sleep, sleep>awake, awake>getup, negative durations → Error=0 = fully consistent chronological order
```

Tracks four error types: `bed > sleep`, `sleep > awake`, `awake > getup`, negative durations.
 **Error=0** indicates fully consistent chronological ordering.
