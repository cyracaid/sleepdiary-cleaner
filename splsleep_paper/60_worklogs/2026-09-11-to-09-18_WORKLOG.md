## 1. External critique → validation hardening (Wave A)

Two external reviews of the GitHub repo (evaluated as "early-stage research package, 3.5/5") flagged three gaps: synthetic-benchmark circularity (0.995 recall = detector detecting its own injected errors), no threshold operating-point analysis, and a benchmark table without precision/FAR columns.

### 1.1 Operating-point threshold sweep (`validation/synthetic/operating_point_sweep.R`)
- 20-point grid: `swap_threshold_hours {1,2,3,4,5}` × `max_gap_hours {8,10,12,14}` on the fixed enrichment benchmark
- Predefined selection rule (not post-hoc): primary recall ≥ 0.95 → secondary min FAR_flag → tie nearest (3,12)
- **Result: flat plateau** — recall ~0.995 and FAR 0 at every point; defaults (3,12) are a validated operating point, not an arbitrary heuristic. This directly answers "why 3 h and 12 h?"
- Outputs: `results/operating_point_sweep.csv`, `operating_point_selection.csv`
- Reproducibility gap found & fixed: the harness had no `set.seed` at the point of use; sweep pins seeds per grid point

### 1.2 Benchmark table (`validation/synthetic/benchmark_table.R`)
- **Control-row miscompute fixed**: `detection_outcomes_v4_current.csv` counted the 1,609 clean-control rows as MISSED (they carry no injected error, so CORRECT is structurally 0) → correct_pct 0 read as "0% correct"
- Detection ≠ correction kept separate: `detected` (pipeline acted) vs `correctly_detected` (right value), plus `false_correction` (misrepaired), per-category recall, pooled precision, control FAR_flag/FAR_alter
- Output: `results/benchmark_table.csv`; both new sections wired into `VALIDATION_REPORT.md` (rendered from CSVs, nothing hand-typed)

### 1.3 Citation metadata
- `CITATION.cff` + `inst/CITATION` + `.zenodo.json` (DOI placeholder for Zenodo after first GitHub release archive)
- `inst/CITATION` fixed to bibtype Manual (Article requires a journal field — CRAN check WARNING)

## 4. Figure tree redesign + rendering bug hunt

### 4.1 Figure tree restructure (per VISUALIZATION_TREE_PROPOSAL)

### 4.2 Fig 15 blank figure — two-layer root cause
1. Data source was `checkforerrors_processed` (the review QUEUE). On real data, 272 SELF_REPORTED_FLAG + 149 metric rows were all human-accepted (`confirmed_not_error_do_not_correct`) → queue nearly empty → blank. Fixed: read `corrected_ema_data` Step-6 `error_type`/`unusual_type` (34 rows, independent of later review).
2. Even then, the de-identified dataset normalizes all corrected timestamps to a single date (2000-01-01) → `geom_area` on one x position renders empty panel. Fixed: `n_distinct(date) < 2` degrades to per-type count bars. Wording reframed non-destructively ("a flag is not a verdict").

### 4.3 print() of patchwork corrupts non-interactive devices (confirmed by pixel analysis)
- Root cause of "overlapping tables" in all_figures_review.pdf: `print(patchwork)` into pdf()/png() opened by Rscript renders the layout corrupt — 99.7% dark pixels vs the same plot via ggsave (clean)
- Every multi-panel figure (Fig 2/13/13B/C/D/P26) looked like piled tables in the PDF while PNGs were fine
- Fix: drop the pdf() device; build the review PDF at script end from the saved PNGs via magick → pixel-identical to deliverables

### 4.4 Fig 13 table overflow — measured heights
- severity_tab (11 rows) + flag_tab (7 rows) had hardcoded unit(1.5in)/unit(1.2in) panels; tableGrob is not compressed by patchwork, so taller-than-guessed content overflowed onto the table below
- Fix: `.tbl_height_in()` measures each table's actual height (grid::convertHeight(sum(tbl$heights), "in") + margin); all panel heights in inches; `save_png(h = total)` grows the canvas (14×9.9in verified); severity and flag tables render in separate bands

### 4.5 Fig 11/14/16 silent skips
- Fig 11: 3-level nested if with no else → silent skip. Full else cascade + `.mark_skip()` with reason.
- Fig 14/16: depend on the (nearly empty on real data) review queue = good outcome; now `.mark_skip()` + `.explain_no_review_figures()`.
- End-of-script missing-figure check: expected list vs disk → console report + `figures_not_generated.csv` + red/amber footer on the contact sheet (make_figure_index.R).
- Fixed ordering bug: `generate_appendix_ledger()` ran AFTER the missing check → A1 falsely reported missing every run.
